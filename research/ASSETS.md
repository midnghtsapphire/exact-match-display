# Research Engine Assets

This file tracks the reusable research inputs used to produce go-to-market output for Exact Match Display.

## Core assets

- **Customer profile seeds:** consumer, freelancer/creator, small-team buyer profiles.
- **Problem taxonomy:** subscription sprawl, recurring-cost visibility gaps, cancellation friction.
- **Messaging bank:** pain-point copy, value-proposition variants, CTA variants.
- **Channel hypotheses:** Product Hunt, SEO content clusters, creator partnership lanes.

## Maintenance rule

When adding new campaign or feature research, update this asset list first, publish outputs in `research/ARTIFACTS.md`, then add recommended next actions to `research/SUGGESTIONS.md`.
